Что это за система

WorkShop Track — это информационная система для учёта и контроля расходования материалов в учебной мастерской. Она помогает вести прозрачный учёт остатков, фиксировать списания и формировать отчётность.

Система разработана в рамках учебной практики по специальности «Информационные системы и программирование» и представляет собой полноценное веб-приложение с серверной частью, базой данных и клиентским интерфейсом.

Какие задачи решает

  • Ведение реестра материалов с указанием нормы расхода и остатка.
  • Фиксация списаний по актам с указанием причины и даты.
  • Контроль остатков и автоматическая подсветка позиций ниже нормы.
  • Поиск по материалам в реальном времени.
  • Экспорт актов списания в CSV для отчётности.
  • Разграничение доступа через регистрацию и вход.
  • Хранение данных в PostgreSQL, доступ с любого устройства.
  • Обмен данными между клиентом и сервером через REST API.

Как это работает

Система построена по клиент-серверной архитектуре. Пользователь работает с веб-интерфейсом, написанным на HTML, CSS и JavaScript. Все действия отправляются на сервер через fetch API в формате JSON.

Серверная часть написана на языке Go и обрабатывает запросы к базе данных PostgreSQL. Данные хранятся в трёх таблицах: materials (материалы), acts (акты списания) и users (пользователи).

Все операции — добавление, редактирование, удаление, пополнение остатка и списание по акту — выполняются через SQL-запросы и сохраняются в базе данных. Это обеспечивает сохранность информации и доступ к ней с любого устройства.

Для кого

Система предназначена для студентов, мастеров и преподавателей учебных мастерских, а также для любых организаций, где ведётся учёт расходных материалов.

Структура базы данных

В базе данных workshoptrack используются три таблицы:

  • materials — id, name, unit, norm, balance.
  • acts — id, material_id, qty, reason, created_at.
  • users — id, username, email, password.

Таблица acts связана с таблицей materials через внешний ключ material_id. Это обеспечивает целостность данных при удалении материала — все связанные акты также удаляются.

Основные возможности

  • Добавление новых материалов с указанием нормы расхода.
  • Редактирование названия, единицы измерения и нормы.
  • Пополнение остатков материалов.
  • Списание материалов по актам с указанием причины.
  • Отмена последнего списания.
  • Просмотр журнала актов списания с датой и причиной.
  • Экспорт актов в CSV-файл.
  • Поиск по названию материала.
  • Статистика: всего материалов, ниже нормы, количество актов.
  • Регистрация и вход пользователей.
